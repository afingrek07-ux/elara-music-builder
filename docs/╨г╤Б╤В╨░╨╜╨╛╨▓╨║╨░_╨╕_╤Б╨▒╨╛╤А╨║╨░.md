# Как получить установщик ElaraMusicBuilder_Setup.exe

Установщик собирает GitHub Actions — бесплатный сервер сборки с Windows. Вам не нужны Visual Studio, Python, PowerShell или командная строка: всё делается в браузере.

## Шаг 1. Аккаунт и репозиторий

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. Нажмите **+** справа вверху → **New repository**.
3. Название, например, `elara-music-builder`. Можно выбрать **Private** (закрытый).
4. Нажмите **Create repository**.

## Шаг 2. Загрузите файлы

1. Распакуйте архив `ElaraMusicBuilder_source.zip` на компьютере.
2. На странице нового репозитория нажмите ссылку **uploading an existing file** (или **Add file → Upload files**).
3. Откройте распакованную папку `ElaraMusicBuilder`, выделите **всё её содержимое** (папки `src`, `installer`, `docs`, `tests`, `.github` и файлы) и перетащите в окно браузера.
   - Папка `.github` в Windows может быть скрытой. Включите в Проводнике: **Вид → Показать → Скрытые элементы**.
   - Проверьте, что среди загружаемых файлов есть `.github/workflows/build.yml` — без него сборка не начнётся.
4. Внизу нажмите **Commit changes**.

## Шаг 3. Дождитесь сборки

1. Откройте вкладку **Actions** в репозитории.
2. Появится сборка «Сборка установщика Elara Music Builder». Она идёт примерно 10–20 минут.
3. Зелёная галочка ✅ — установщик готов. Красный крестик ❌ — откройте сборку, нажмите на шаг с ошибкой и пришлите мне текст ошибки.

На странице сборки, в разделе **Summary**, появится таблица автотестов: они проверяют видеодвижок на настоящем FFmpeg под Windows.

## Шаг 4. Скачайте и установите

1. На странице завершённой сборки внизу, в разделе **Artifacts**, нажмите **ElaraMusicBuilder_Setup**.
2. Скачается ZIP-архив. Распакуйте его — внутри `ElaraMusicBuilder_Setup.exe`.
3. Дважды щёлкните по `ElaraMusicBuilder_Setup.exe` → **Установить** → **Готово**.
4. Запускайте программу с ярлыка на рабочем столе.

> Windows может показать окно SmartScreen «Windows защитила ваш компьютер», потому что установщик не подписан платным сертификатом. Нажмите **Подробнее → Выполнить в любом случае**.

## Обновление программы

Если я пришлю исправленные файлы, загрузите их в репозиторий так же (**Add file → Upload files**) — новая сборка запустится автоматически.

## Постоянная ссылка на установщик (необязательно)

Если создать в репозитории релиз с тегом, начинающимся на `v` (например, `v4.0.0`: **Releases → Draft a new release → Choose a tag → v4.0.0 → Publish**), сборка автоматически прикрепит `ElaraMusicBuilder_Setup.exe` к релизу.

## Для разработчиков: локальная сборка

Требуется Windows, .NET 8 SDK и Inno Setup 6:

```
dotnet publish src/ElaraMusicBuilder/ElaraMusicBuilder.csproj -c Release -r win-x64 --self-contained true -o publish
# положить ffmpeg.exe и ffprobe.exe (GPL-сборка с libx264) в publish\ffmpeg\
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\ElaraMusicBuilder.iss /DPublishDir=..\publish
```

Готовый файл: `dist\ElaraMusicBuilder_Setup.exe`.
