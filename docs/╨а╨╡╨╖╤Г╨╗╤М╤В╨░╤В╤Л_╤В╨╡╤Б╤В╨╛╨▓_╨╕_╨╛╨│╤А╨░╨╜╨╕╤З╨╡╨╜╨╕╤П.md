## Что будет проверено автоматически при сборке на Windows

`tests/EngineTests` — это настоящий C#-код программы, запущенный с FFmpeg 7.1 под Windows. Он выполняется в GitHub Actions при каждой сборке, а таблица результатов появляется на странице сборки. Тесты охватывают:

импорт и измерение · сортировку · тайм-коды для всех режимов переходов и для видео длиннее часа · склейку альбома · 5 визуализаторов × 5 стилей подсветки × разные движения фото · 4 режима цикла видеофона · полное видео 1080p с проверкой размера и длительности · отмену экспорта с удалением незавершённого файла · сохранение и открытие `.elara` · предупреждение об отсутствующих файлах · кадр предпросмотра · экспорт альбома в MP3 · описание YouTube.

## Что НЕ проверено (честно)

- **C#-код не компилировался в среде разработки** — там нет .NET и Windows. Первая сборка в GitHub Actions — это и есть первая компиляция. Если она покажет ошибку, пришлите текст — исправлю.
- **Интерфейс WPF не запускался и визуально не проверялся.** Дизайн сделан по вашему референсу и палитре, но окончательный вид нужно посмотреть на вашем компьютере.
- **Установка на чистую Windows** не проверялась. Установщик собирается только в GitHub Actions.
- **Ускорение видеокартой** (NVENC, Quick Sync, AMF) не проверялось на реальном оборудовании. При ошибке программа автоматически переключается на процессор.
- **Многочасовые видео** (2–3 часа) не рендерились целиком. Синхронность обеспечивается архитектурно: постоянная частота кадров, звук — единый WAV, длительность задаётся точно, итог проверяется FFprobe.

## Известные ограничения

1. **Предпросмотр — настоящий кадр, а не живое видео.** Кадр рисуется тем же движком, что и итоговое видео, и обновляется после каждого изменения. Во время воспроизведения он обновляется примерно раз в 2 секунды. Чтобы увидеть движение, используйте «Тест 20 сек».
2. **Перемещение элементов** — кликом или перетаскиванием по кадру. Ручек для изменения размера нет: размер задаётся ползунками.
3. **Умное зацикливание** ищет лучшую точку склейки, но идеально бесшовный цикл зависит от ролика.
4. **«Вперёд-назад»** использует первые 20 секунд видео (фильтр reverse держит кадры в памяти).
5. **Цвет частиц** влияет только на яркость; оттенок частицы берут от фона.
6. **Подчёркивание** в треклисте имеет расчётную длину и может быть чуть короче или длиннее текста.
7. **Редактор обложки** использует шрифты Windows; импортированные в программу шрифты в нём пока недоступны.
8. **Скорость создания видео** зависит от процессора. Частицы, движение фото и сильное свечение замедляют рендер. Для 4K рекомендуется видеокарта.
9. **SmartScreen:** установщик не подписан платным сертификатом, поэтому Windows может показать предупреждение («Подробнее → Выполнить в любом случае»).
10. **FFmpeg** поставляется в GPL-сборке (нужна для H.264 / x264) как отдельная программа в папке `ffmpeg`. Лицензия и ссылки на исходный код — в `THIRD_PARTY_NOTICES.txt`.
