# Elara Music Builder 4.0

Программа для Windows 10/11 (64-бит), которая превращает музыку в длинное видео для YouTube: фон, эквалайзер, треклист с подсветкой текущей песни, логотип и точные тайм-коды.

## Как получить установщик `ElaraMusicBuilder_Setup.exe`

Установщик собирается автоматически на серверах GitHub (бесплатно, без командной строки). Пошаговая инструкция: **[docs/Установка_и_сборка.md](docs/Установка_и_сборка.md)**.

Коротко:
1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него содержимое этого архива (кнопка **Add file → Upload files**).
3. Откройте вкладку **Actions** и дождитесь зелёной галочки (≈10–15 минут).
4. Скачайте **ElaraMusicBuilder_Setup** внизу страницы сборки, распакуйте и запустите.

## Что внутри

| Папка | Содержимое |
|---|---|
| `src/ElaraMusicBuilder` | Исходный код программы (C#, .NET 8, WPF) |
| `installer` | Сценарий установщика Inno Setup |
| `.github/workflows/build.yml` | Автоматическая сборка: программа + FFmpeg + автотесты + установщик |
| `tests/EngineTests` | Автотесты видеодвижка (запускаются при сборке на Windows) |
| `tests/graph_mirror.py` | Проверочная копия построителя графов FFmpeg (использовалась для тестов при разработке) |
| `docs` | Руководство пользователя, установка, результаты тестов, ограничения, лицензии |

## Архитектура

- **Интерфейс:** WPF (.NET 8), светлая тема, поддержка высокого DPI (Per-Monitor V2) — чёткость на 125 %, 150 % и 200 %.
- **Обработка звука и видео:** FFmpeg/FFprobe запускаются как отдельные процессы. Программа строит граф фильтров FFmpeg (`Services/FilterGraphBuilder.cs`) и передаёт его через файл — без ограничений длины командной строки.
- **Звук:** `AudioAlbumBuilder` измеряет точную длину каждой песни по сэмплам, склеивает альбом (паузы / fade / crossfade), выравнивает громкость в два прохода (EBU R128, loudnorm) и пишет WAV-кэш.
- **Тайм-коды:** `Timeline` рассчитывает начала песен из точных длительностей с учётом пауз и перекрытий. Те же числа используются для подсветки треклиста в видео, поэтому описание и видео совпадают.
- **Видео:** `VideoExporter` собирает H.264 + AAC MP4, использует видеокарту (NVENC / Quick Sync / AMF), при сбое — процессор (x264). Результат проверяется через FFprobe до сообщения об успехе.
- **Проекты:** JSON-файлы `.elara`, автосохранение раз в минуту, восстановление после сбоя.
- **Установщик:** Inno Setup, установка в профиль пользователя без прав администратора, ярлыки на рабочем столе и в меню «Пуск», деинсталлятор.
